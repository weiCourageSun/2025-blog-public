# 复变函数学习

## 对于复变函数，按照实数的学习过程。复数->复变函数->微分->积分->级数

例如

给出数Z=x + i y  对应在复平面(x,y)该点

给出函数f(z) = u + i v  其中 u 和 v 可以分别是z的函数，复平面中z的(x,y)坐标值映射在u,v中，可以确定f(z)在复平面的位置。

对于复变函数导数定理存在的学习

1.C-R条件，即u偏x = v 偏y  且 v偏x = u偏y 

2.偏导ux, uy, vx, vy 在该点存在且连续

## 下面引入解析概念，认为解析是从实函数中x微分增量一维左右两侧 上升到z0包括一个实心领域内的范围拓展成二维

解析主要针对区域性概念，解析点包含奇点，解析点<->奇点，对于奇点，可以理解为实数函数无定义域的点，例如f(x) = 1/x  定义域为x != 0  在复变函数里，若f(z) = 1/z  其中z != 0 ，z就是奇点。    

对于奇点的判别较为容易，只要在导数存在定理不满足的情况的点就是奇点
